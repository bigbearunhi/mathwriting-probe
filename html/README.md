# Local HTML viewers

Download/clone this repository and open the HTML files in a browser. GitHub source view does not execute them.

- [Training samples](training-viewer/index.html): 124,500-step model; 512 real and 512 synthetic training-pool samples.
- [Validation recognition](error-viewer/index.html): 74,500-step model; 2,048 validation samples.
- [Preprocessing geometry](preprocess-viewer/index.html): 300 sample comparisons; keep data.js next to index.html.

These pages include small sampled ink geometry and labels required for visualization. They do not include the full datasets, feature databases, or model checkpoints. Each viewer displays one sample at a time. These are fixed snapshots, not live training dashboards.
